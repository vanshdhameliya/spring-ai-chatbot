# Spring AI Chatbot

A simple AI chatbot built with **Spring Boot, Spring AI, and OpenAI/OpenRouter**.

This is my first Spring AI project, created to understand conversation history, context, system instructions, memory, streaming, and hallucinations.

## Features

* AI-powered chatbot
* Conversation history
* System instructions
* Chat memory
* REST API
* OpenAI/OpenRouter API integration

Get an API key from OpenAI Platform or OpenRouter and configure it in the application.
